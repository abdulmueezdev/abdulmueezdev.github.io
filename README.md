# Abdul-Mueez Shahid | Portfolio

[![Live Site](https://img.shields.io/badge/LIVE-abdulmueezdev.github.io-55E6C1?style=for-the-badge&logo=github)](https://abdulmueezdev.github.io)

A brutalist, terminal-inspired personal portfolio built with Next.js, React Three Fiber, and Framer Motion.

## Tech Stack

- **Framework:** Next.js 16 (App Router)
- **Styling:** Tailwind CSS + Vanilla CSS
- **Animation:** Framer Motion
- **3D Graphics:** React Three Fiber (`@react-three/fiber`, `@react-three/drei`)
- **Deployment:** GitHub Pages

## Features

- Interactive 3D laptop hero with boot sequence animation
- Terminal-inspired UI with neon accents (`#55E6C1`, `#6C5CE7`)
- Project showcase with `OrbitCardStack` hover interactions
- Contact form powered by FormSubmit.co
- Fully responsive (desktop & mobile)
- Static export — no backend, no database

## Projects Showcased

1. **Alucard** — AI persona chatbot
2. **EduIG-Pipeline** — Instagram data extraction pipeline
3. **Nabeel Photographic Moments** — Photography portfolio
4. **LeadMap** — Map scraping and lead scoring engine
